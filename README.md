# MacUI

Windows 11（および Windows 10）のプライマリモニターのタスクバーを、**Liquid Glass（macOS Tahoe 風）** のフローティング Dock・メニューバー・コントロールセンター・ネットワークパネル・アプリ ランチャーに置き換える、超軽量ネイティブ Rust アプリです。

単一バイナリ（約 1 MB）で動作し、**.NET・WebView2・Visual C++ 再頒布可能パッケージ等の外部ランタイムは一切不要**です。

## 主な特徴

- **Apple HIG 準拠の Liquid Glass レンダリング（GPU 合成）**
  - `DWMWA_USE_HOSTBACKDROPBRUSH` + `Windows.UI.Composition` による **Dual-Scale Chromatic パイプライン**（近距離光学屈折＋広域カラーブルームを単層合成）。ソフトウェア描画（WARP）や透明効果オフの環境にも自動フォールバックします。
  - 背景の輝度・色調をイベント駆動でサンプリングし、明背景／暗背景に合わせてガラス質感と文字・アイコン色を自動適応（Adaptive Polarity）。
  - コントロールセンター（4 モジュール）、ネットワークパネル（3 モジュール）、アプリ ランチャー（3 モジュール）はすべて独立したフローティング Liquid Glass モジュールとして描画します。

- **滑らかな macOS 風 Dock**
  - Windows タスクバーのピン留め・起動中アプリを同じ順序で自動同期。Steam / Discord / Epic Games / Electron 等のマルチプロセス・トレイ常駐アプリも正しく起動・フォーカスできます。
  - ホバー時のコサイン波形拡大アニメーション、ガラスピルの動的伸縮、バウンスアニメーション、アクティブアプリ発光インジケーター、フローティング Liquid Glass ツールチップ。
  - 112px 高解像度アイコン（ショートカット矢印なし）。透過面積が大きいアイコンにはアイコンの色調に調和する macOS 風スカークル背景（パールオフホワイト／ディープスレート）を自動付与します。
  - 自動非表示、サイズ（小・標準・大）、ガラス質感（クリア・標準・ダーク）、拡大強度（オフ・弱・標準・強）をライブ切替可能。

- **Liquid Glass アプリ ランチャー（Launchpad）**
  - Dock 右端の 3×3 グリッドアイコン、メニューバーの `🔍`、または **`Ctrl + Alt + Space`** で即起動。
  - 日本語 IME 変換中リアルタイム絞り込み・英日エイリアス検索・前後ページアイコンプリロード・ページスライド＆ホバースプリングアニメーションに対応。右クリックで直接 Dock にピン留めできます。

- **macOS 風メニューバー & フローティングパネル**
  - 左側: ブランドメニュー、アクティブアプリ名（リアルタイム追従）、`ファイル`・`表示`（`shell:` 既知フォルダー対応で OneDrive リダイレクト環境でも正確に展開）・`ウィンドウ` メニュー。
  - 右側: 隠れたトレイアイコン（`^`）、IME バッジ（クリック切替）、バッテリー（搭載 PC のみ表示）、IP Helper + 動的ロード Native Wi-Fi による有線イーサネット／Wi-Fi／VPN 表示 & ネットワークパネル、CoreAudio 音量（ホイール調整・右クリックミュート）、コントロールセンター、時計＋通知ドット。

- **徹底した軽量設計 & マルチ環境対応**
  - `shell:AppsFolder` 列挙や UWP アイコンデコードは短命サブプロセスへ隔離し、常駐プロセスに XAML / Shell 拡張 DLL を一切読み込ませません。
  - `wlanapi.dll` は動的ロードのため、Wi-Fi 機能のないデスクトップ／LTSC／VM 環境でもクラッシュせず動作します。
  - Per-Monitor DPI v2（100%〜200%）、マルチモニター（プライマリモニターのみ置換しサブモニターはそのまま維持）、日本語／英語 Windows（フォント自動フォールバック）に対応します。

## 使い方・安全設計

1. `target\release\macui.exe` を実行します（スタートアップへの自動登録は行いません）。
2. 終了して元の Windows タスクバーへ戻す方法:
   - **`Ctrl + Alt + Q`**
   - 左上のブランドメニュー → **「MacUI を終了して元に戻す」**
   - Dock 右端の設定 → 終了、またはコマンドライン `macui.exe --quit`
3. 強制終了時の安全機構:
   - 独立した軽量ガードプロセス（`--restore-guard`）が常駐し、本体が予期せず終了しても Windows タスクバーとデスクトップ作業領域（WorkArea）を自動復元します。
   - 両プロセスを同時に強制終了した場合は、同梱の `restore-taskbar.cmd`（または `macui.exe --restore`）を実行すると即座に復元できます。
4. 設定とカスタムピン留め項目（ドラッグ＆ドロップで最大 6 個）は `%LOCALAPPDATA%\MacUI\dock.txt` に保存されます。

## 動作環境

- **OS**: Windows 11（推奨）/ Windows 10（64-bit, 1803 以降）
- **追加ランタイム**: 不要（標準 Windows システム DLL のみ使用）

## ビルド方法

Windows 環境で [Rust](https://www.rust-lang.org/)（MSVC または GNU ツールチェーン）を用意し、以下を実行します:

```powershell
cargo build --release
```

ビルド完了後、`target\release\macui.exe` が生成されます。MSVC ツールチェーン利用時は `.cargo/config.toml` により CRT が静的リンクされるため、生成された単体 `.exe` をそのまま別 PC へコピーして実行できます。

テストの実行:

```powershell
cargo test
```
